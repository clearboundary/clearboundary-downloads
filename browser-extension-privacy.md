# ClearBoundary Selective Filter privacy notice

This notice applies to version 0.1.0 of ClearBoundary Selective Filter for Chrome, Microsoft Edge and Firefox.

## What the extension uses

ClearBoundary inspects the webpages you open in supported browsing windows. It uses displayed text, image pixels, the current page origin and selected media URLs to decide what to show. On supported direct-video pages in Chrome and Edge, the extension can inspect frames locally when its limited filtered playback is used. Firefox provides text and image filtering.

Filtering and the toolbar status check run on your device. ClearBoundary does not receive your page contents, browsing history, images, video frames or filter decisions. The extension does not use ads, analytics, tracking or a cloud classifier. It does not sell or share browsing data for other purposes. ClearBoundary Selective Filter uses the information it accesses only for filtering and checking the filter's status, in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

## Requests to websites

The extension may request a supported image from the original host listed on the page. Filtered direct video uses a source on the current website. These requests omit credentials and the referrer and reject redirects. A website or media host can still see requests it receives and apply its own privacy policy. No page contents are sent to ClearBoundary or to an outside classification service.

## Retention and controls

The extension processes webpage content in memory and does not keep a browsing or classification history. The Firefox add-on may store a flag in the browser profile to recognize that mandatory policy originally installed it. The flag contains no webpage data. The extension does not sync that flag. The browser removes extension storage when the add-on is removed.

Use the browser's extension settings to manage a manually installed extension. If ClearBoundary Windows setup manages the extension, use ClearBoundary's authorized restoration process to remove its policy. Normal store installation and update requests are handled by your browser and its store.

ClearBoundary's separate Windows site-reporting app only sends a report when the user chooses to submit one. That app is covered by the separate [site-reporting privacy notice](https://clearboundary-report-test.onrender.com/reporting/privacy).

For privacy questions or help, email **dwight@clearboundary.org**.
